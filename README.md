# Tab Sorter (タブソーター)

Microsoft Edge および Google Chrome で動作する、軽量・高機能・セキュアなタブ並び替え拡張機能（Manifest V3）です。

![Tab Sorter Icon](icons/icon128.png)

---

## 主な機能と特長

1. **ワンクリックで昇順・右クリックで降順ソート**
   - **左クリック**: タブを **昇順（A → Z, 1 → 9）** で瞬時に並び替えます。
   - **右クリック**: コンテキストメニューから **「降順でソート (Z → A, 9 → 1)」** や「昇順でソート」を選択できます。
   - ソート実行後、ツールバーアイコンのバッジに一時的に `ASC` または `DESC` が表示され、視覚的に完了がわかります。

2. **全角英数・自然順ソート（Natural Sort）に完全対応**
   - **自然順ソート**: 「タブ1, タブ2, タブ10」が「タブ1 → タブ2 → タブ10」の順序で正しく整列します（「1, 10, 2」のような辞書順崩れが発生しません）。
   - **全角対応**: 全角数字（`１`, `２`, `１０`）や全角アルファベット（`Ａ`, `ａ`, `Ｂ`）も半角と等価に自然順ソートされます。

3. **タブグループの維持と末尾（一番下）配置**
   - タブグループの所属関係を崩さずに維持します。
   - **配置ルール**:
     1. 最前列：ピン留めタブ（ピン留めタブ内でソート）
     2. 次列：タブグループ外の通常タブ（グループ外タブ同士でソート）
     3. 末尾列（一番下）：**各タブグループを配置**
        - 各タブグループ自体を **「タブグループ名」** でソート（昇順/降順はタブと連動）。
        - 各タブグループ内のタブも、**そのグループ内で** ソート（昇順/降順はタブと連動）。

4. **最高水準のセキュリティとプライバシー**
   - **サードパーティライブラリ不使用**: 外部ライブラリ（npm パッケージ、CDN 等）への依存ゼロ。完全な Vanilla JavaScript（Web標準API）のみで実装。
   - **最小権限の原則（Least Privilege）**: 必要な権限（`tabs`, `tabGroups`, `contextMenus`）のみを要求。`<all_urls>` などのWebサイト閲覧履歴やDOMへのアクセス権限は一切持たず、通信（Fetch/XHR）も一切行いません。
   - **CSP準拠**: `eval` や `innerHTML` は不使用。
   - **多重実行防止ロック**: 連打によるタブインデックスの不整合を防止するロック機構を搭載。

5. **視認性に優れた専用アイコン**
   - タブが上下に重なり、昇順・降順で順序が入れ替わる様子を直感的に表現したモダンなベクターアイコン（16px, 32px, 48px, 128px）。

## インストール手順

本拡張機能は、Chrome や Edge に「パッケージ化されていない拡張機能」として簡単にインストールできます。

### Google Chrome の場合
1. Chrome を起動し、アドレスバーに `chrome://extensions` と入力して Enter を押します。
2. 画面右上にある **「デベロッパー モード」** のトグルスイッチを **ON** にします。
3. 画面左上に表示される **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
4. 本フォルダ（`Tab_Sorter`）を選択します。
5. ツールバーのパズルピースアイコン（拡張機能メニュー）から「Tab Sorter」をピン留めすると、常にアイコンが表示されます。

### Microsoft Edge の場合
1. Edge を起動し、アドレスバーに `edge://extensions` と入力して Enter を押します。
2. 画面左側のメニュー（または上部）にある **「開発者モード」** のトグルスイッチを **ON** にします。
3. **「展開して読み込む」**（Load unpacked）ボタンをクリックします。
4. 本フォルダ（`Tab_Sorter`）を選択します。
5. ツールバーの拡張機能アイコンから「Tab Sorter」の目のアイコンをクリックして、ツールバーに固定表示します。

## 使い方

| 操作 | 動作 |
| :--- | :--- |
| **アイコンを左クリック** | 現在のウィンドウのタブおよびタブグループを **昇順** でソート |
| **アイコンを右クリック →「降順でソート」** | 現在のウィンドウのタブおよびタブグループを **降順** でソート |
| **アイコンを右クリック →「昇順でソート」** | コンテキストメニューから明示的に **昇順** でソート |

---

## テストの実行

ロジックのテストを行いたい場合は、Node.js がインストールされた環境で以下を実行してください：

```bash
node test_suite.js
```
自然順ソート、全角文字処理、タブグループの維持・末尾配置シミュレーションが全て検証されます。
