# Tab Sorter for Chromium (タブソーター)

Microsoft Edge および Google Chrome で動作する、軽量・高機能・セキュアなタブ並び替え拡張機能（Manifest V3）です。  
タイトルやURLに基づいた自然順ソート、タブグループの所属維持、キーボードショートカット、詳細なオプションカスタマイズに対応しています。

![Tab Sorter Icon](icons/icon128.png)

---

## 主な機能と特長

1. **ワンクリックソート & コンテキストメニュー**
   - **左クリック**: ツールバーのアイコンをクリックするだけで、設定されたデフォルトソート（初期値: URL昇順）を瞬時に実行します。
   - **右クリック**: メニューから「タイトル昇順」「タイトル降順」「URL昇順」「URL降順」「同一ドメインでタブグループを作成」「設定画面」を直接選択できます。
   - 処理完了後はアイコンのバッジに一時的に `ASC`, `DESC`, `U-UP`, `U-DN`, `N GRP` が表示され、視覚的に完了が把握できます。

2. **同一ドメインでのタブグループ自動作成（新機能）**
   - 右クリックメニューの **「同一ドメインでタブグループを作成」** から実行できます。
   - **グループ未所属のタブのみ対象**: 既にグループに属しているタブやピン留めタブはそのまま保護されます。
   - **2タブ以上のドメインを自動集約**: 単一のタブしかないドメインはグループ化せずそのまま残すため、タブバーがグループで埋まりません。
   - **先頭位置と順序の維持**: そのタブグループに所属するタブの中で最も先頭にあった位置にグループが作成され、グループ内の並び順も実行前の順序を保ちます。
   - **ドメイン名をグループ名に採用**: `www.` を除いたホスト名（例: `google.com`, `github.com`）がグループ名になります。

3. **URLソートに対応（ドメイン優先 & パスの自然順）**
   - **ドメイン階層優先（推奨）**: ホスト名（ドメイン）を優先してソートするため、同じWebサイトのタブが隣同士に綺麗にまとまります（`www.` の有無も吸収）。
   - **パス・クエリの自然順**: 同一ドメイン内ではパス名（`/page2`, `/page10` 等）が自然順で並び替わります。
   - オプション画面にて「完全URL比較（文字列全体）」への切り替えも可能です。

4. **キーボードショートカット対応 & 自由に変更可能**
   - マウスを使わずに、いつでもキーボードから瞬時にタブを並び替えることができます。
   - ブラウザ標準のショートカット設定ページと連携し、オプション画面から簡単にキーの組み合わせを変更・カスタマイズできます。

5. **全角英数・自然順ソート（Natural Sort）に完全対応**
   - **自然順ソート**: 「タブ1, タブ2, タブ10」が「タブ1 → タブ2 → タブ10」の順序で正しく整列します（「1, 10, 2」のような辞書順崩れが発生しません）。
   - **全角対応**: 全角数字（`１`, `２`, `１０`）や全角アルファベット（`Ａ`, `ａ`, `Ｂ`）も半角と等価に自然順ソートされます。

6. **タブグループの所属維持と末尾（一番下）配置**
   - タブグループの所属関係を崩さずに維持します。
   - **配置ルール**:
     1. **最前列**: ピン留めタブ（ピン留めタブ内でのみソート）
     2. **中間列**: タブグループ外の通常タブ（グループ外タブ同士でソート）
     3. **末尾列（一番下）**: **各タブグループを配置**
        - 各タブグループ自体を **「タブグループ名」** でソート。
        - 各タブグループ内のタブも、**そのグループ内で** ソート。

7. **最高水準のセキュリティとプライバシー**
   - **サードパーティライブラリ不使用**: 外部ライブラリ（npm パッケージ、CDN 等）への依存ゼロ。完全な Vanilla JavaScript（Web標準API）のみで実装。
   - **最小権限の原則（Least Privilege）**: 必要な権限（`tabs`, `tabGroups`, `contextMenus`, `storage`）のみを要求。Webサイトの閲覧履歴やDOMへのアクセス権限、外部通信（Fetch/XHR）は一切行いません。
   - **多重実行防止ロック**: 連打によるタブインデックスの不整合を防止するロック機構を搭載。

プロジェクト内の構成と、各ファイル・フォルダの役割・責務は以下の通りです。ソースコード内にも人間が読んで理解しやすい詳細な日本語コメントが記載されています。

├── background.js              # バックグラウンド・サービスワーカー (ソート処理・ショートカット受信)
├── options.html               # オプション設定画面のHTML (UI構造)
├── options.css                # オプション設定画面のスタイルシート (デザイン・ダークモード対応)
├── options.js                 # オプション設定画面のスクリプト (ショートカット取得・設定の保存)

├── README.md                  # 本ドキュメント (プロジェクト概要・仕様・ファイル説明)
├── .gitignore                 # Gitのバージョン管理除外設定
├── icons/                     # 拡張機能のアイコン画像格納フォルダ

## キーボードショートカット一覧

デフォルトで以下のショートカットキーが割り当てられています：

| ショートカットキー | 動作内容 |
| :--- | :--- |
| <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | 現在のウィンドウのタブを **タイトル昇順** でソート |
| <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>D</kbd> | 現在のウィンドウのタブを **タイトル降順** でソート |
| <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>U</kbd> | 現在のウィンドウのタブを **URL昇順**（ドメイン・パス順）でソート |
| <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>J</kbd> | 現在のウィンドウのタブを **URL降順**（ドメイン・パス順）でソート |

### ショートカットの変更方法（オプションでの変更）
1. ツールバーの拡張機能アイコンを **右クリック** し、**「設定・ショートカット変更...」** をクリックします。
2. 設定画面の最上部にある **「ショートカット設定画面を開く」** ボタンをクリックします。
3. ブラウザのショートカット管理画面が開くので、**「Tab Sorter for Chromium」** の項目でお好きなキーを入力して変更してください。

> [!TIP]
> アドレスバーに直接以下を入力して Enter を押すことでもショートカット変更画面を開けます：
> - **Google Chrome の場合**: `chrome://extensions/shortcuts`
> - **Microsoft Edge の場合**: `edge://extensions/shortcuts`

## 使い方（マウス操作）

| 操作 | 動作 |
| :--- | :--- |
| **アイコンを左クリック** | 設定されたデフォルト基準（初期値: URL昇順）でソート |
| **アイコンを右クリック →「タイトル昇順でソート」** | タイトル順（A → Z, 1 → 9）でソート |
| **アイコンを右クリック →「タイトル降順でソート」** | タイトル順（Z → A, 9 → 1）でソート |
| **アイコンを右クリック →「URL昇順でソート」** | ドメイン・URL順（A → Z）でソート |
| **アイコンを右クリック →「URL降順でソート」** | ドメイン・URL順（Z → A）でソート |
| **アイコンを右クリック →「同一ドメインでタブグループを作成」** | 未所属タブを同一ドメイン（2つ以上）ごとに自動でタブグループ化 |
| **アイコンを右クリック →「設定・ショートカット変更...」** | オプション設定画面を開く |

## インストール手順

本拡張機能は、Chrome や Edge に「パッケージ化されていない拡張機能」として簡単にインストールできます。

### Google Chrome の場合
1. Chrome を起動し、アドレスバーに `chrome://extensions` と入力して Enter を押します。
2. 画面右上にある **「デベロッパー モード」** のトグルスイッチを **ON** にします。
3. 画面左上に表示される **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
4. 本フォルダ（`Tab_Sorter_for_Chromium`）を選択します。
5. ツールバーのパズルピースアイコン（拡張機能メニュー）から「Tab Sorter for Chromium」のピン留めをクリックすると、常にアイコンが表示されます。

### Microsoft Edge の場合
1. Edge を起動し、アドレスバーに `edge://extensions` と入力して Enter を押します。
2. 画面左側のメニュー（または上部）にある **「開発者モード」** のトグルスイッチを **ON** にします。
3. **「展開して読み込む」**（Load unpacked）ボタンをクリックします。
4. 本フォルダ（`Tab_Sorter_for_Chromium`）を選択します。
5. ツールバーの拡張機能メニューから「Tab Sorter for Chromium」の目のアイコンをクリックして、ツールバーに固定表示します。

## テストの実行

ロジックの動作検証を行いたい場合は、Node.js がインストールされた環境で以下を実行してください：

```bash
node test_suite.js
```

自然順ソート、全角文字処理、URL階層ソート、タブグループの維持・末尾配置シミュレーションが全て自動検証されます。
